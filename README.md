TLyrics
Your Audio. Your Words. Always Within Reach.

TLyrics is a lightweight macOS audio companion that displays synchronized transcripts and spoken content directly on your MacBook Touch Bar.

Built with Tauri 2, Rust, and native macOS technologies, TLyrics helps users follow podcasts, Islamic lectures, audiobooks, and educational content without constantly switching applications.

✨ Features
Feature	Description
Live Transcription	Follow spoken content through synchronized text.
Touch Bar Integration	Display current spoken words on your MacBook Touch Bar.
Background Mode	Continue processing while using other applications.
Menu Bar Integration	Access TLyrics without cluttering your macOS Dock.
Podcast Support	Follow conversations and discussions more easily.
Learning Companion	Follow lectures, educational content, and audiobooks.
Lightweight	Designed for minimal CPU and memory consumption.
Extensible Architecture	Modular architecture for additional audio platforms.

🚀 Getting Started
1. Clone the repository
bash
git clone https://github.com/YOUR_USERNAME/tlyrics.git
cd tlyrics

2. Run in development mode
bash
cargo tauri dev

3. Build the application
bash
cargo tauri build
